Judge 1 / assurance

Prove the denominator.

If both “expected” and “received” calls come from the same surviving logs, losing a whole call can still produce a false green result.

Revision: an independently justified expected inventory; explicit source authority, completeness and unknown states.

Judge 2 / architecture

Make concurrency safe.

Two calls cannot spend the same remaining budget. Crashes and ambiguous retries must not free money already spent.

Revision: atomic reservation and settlement, durable attempt IDs, immutable specifications and conservative recovery.

Judge 3 / delivery

Finish the scored system.

Adaptive agents add work without automatically adding a completed control or a more trustworthy verdict.

Revision: complete deterministic controls first; CLI first; one bounded Nemotron agent with adaptive mode gated by demonstrated value.

One codebase · logical modules, not a fleet of microservices

The advanced architecture.

The supplied telecom agents remain the system under assessment. ProofLab adds reusable adapters, an enforcement mechanism, an evidence reconciler, three deterministic tests, and a governance/query layer.

Execution

The gateway asks one decision question. The control receives a frozen rule and state. A coordinator commits budget reservation before inference.

Assessment

Raw events reconcile with an independently justified inventory. Deterministic code calculates coverage, drift and spend.

Governance

ServiceNow connects the system, finding, evidence and human owner. Judge queries and exports remain usable without an LLM.

Where the engineering becomes advanced

The token gate must survive races and crashes.

1 / reserve

Account before dispatch.

Calculate a justified input bound plus an enforced output bound. Atomically reserve this amount and create the unique attempt record.

2 / dispatch

Own the attempt.

Conditional dispatch ownership prevents two workers executing the same attempt. New inference retries get new attempt IDs and reservations.

3 / settle

Record actual usage once.

Atomically update attempt state and run totals. Release only unused reservation. If actual usage exceeds the bound, retain the full value and stop admission.

4 / recover

Keep ambiguity visible.

A timeout or expired lease does not prove no spend occurred. Hold ambiguous reservations until reconciliation; prevent stale workers settling twice.

Admission invariant: settled_tokens + outstanding_reserved_tokens ≤ frozen_run_cap
Atomic operation: reserve budget + persist unique attempt → commit → dispatch
Settlement: conditional attempt transition + run totals → one transaction

A single-region DynamoDB transaction is a candidate implementation if the sandbox allows it. Durable attempt records are still necessary; transport retries alone are not an exactly-once inference guarantee. AWS transaction documentation.

Claim strict prevention only after testing all governed paths: every call intercepted, enforceable token bounds, retries, concurrent requests, duplicate delivery and unknown outcomes. If those premises cannot be established, retain honest detection and declare the prevention gap.

A concrete differentiator

Make the system challenge its own conclusions.

Executable attack catalog

Concurrent budget requests, retry burst, duplicate events, missing whole attempt, cross-run mislink, stale rule version, missing metric window and controlled degradation.

Use team-owned assets and approved scenarios. Cloned-export tests stay clearly labelled.

Bounded Nemotron agent

Reads an evidence gap, proposes a hypothesis, and selects an existing authorized test. A deterministic scheduler validates scope and budget before execution.

The model cannot change thresholds, authorize itself or assign the final verdict.

Prove incremental value

Preserve the failing case, apply a permitted fix, and pass a new-run retest. Keep the original failure inspectable.

Adaptive superiority needs an equal-budget comparison with fixed tests. Without that, report the observed finding only.

Model requirement: verify at first access whether supplied Nemotron agents satisfy the organizer requirement. If team-owned usage is mandatory, deploy a minimal bounded assurance agent early. Advanced adaptive episodes remain optional after the evidence system works.

The moment judges should remember

“Remove that record. Does your green result survive?”

The judge selects Control 16 and a run. The tool displays the dated rule, complete attempt inventory, actual usage and source records. On a labelled copied export, one whole call is removed. The observed subtotal falls—but the tool refuses to call that a pass because an expected call is missing.

A separate live, permitted concurrent-call scenario demonstrates the atomic budget gate. A drift case shows an honest breach with a delivered or pending alert. ServiceNow holds the actual remote record and named owner. A new-run retest proves any claimed repair.

Keep the demo compact: query → one operational control → one evidence challenge. Keep other controls and tests available for judge-selected drill-down. Actual overspend and a denied attempt are separate demonstrations; confirm acceptance of any replay or synthetic breach case.
