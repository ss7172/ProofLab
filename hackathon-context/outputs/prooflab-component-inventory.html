Provided environment

ServiceNow and AWS telecom agents, existing gateways/tools, approved NVIDIA inference, ServiceNow governance and permitted compute/storage.

“Provided” means described by the workshop. We still verify access and actual source coverage.

What we build

One assurance package with source adapters, an ingestion/assessment worker and a query/investigation entry point. Add the conditional inline admission hook for prevention, and a local judge CLI with optional UI.

These entry points can share a permitted host. They are not 16 independent microservices.

DynamoDB and S3 are conditional infrastructure mappings; SQLite is a portable query index. The Nemotron investigator is our orchestration code calling an approved model endpoint—not a new GPU deployment.

Where we begin tracing

Start with the system being governed.

M01 · A customer reports a fault.

Illustration: “My mobile data has stopped working.” The provided ServiceNow customer/ticket agent receives or is triggered by the permitted request. It has a business case and customer context. This agent is part of the subject workflow; it is not our evidence investigator.

Before the first governed action, M03 creates or resolves the authorized fault-resolution run—for example FM-001—under the predeclared M04 policy.
