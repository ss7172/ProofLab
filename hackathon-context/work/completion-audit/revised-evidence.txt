THREE REMAINING MATERIAL RISKS

1. HIGH — Baseline missingness contradicts the scoring rule; empty denominators still need guards.
Section5 says missing outcomes are UNKNOWN, “not0 and not excluded,” but computes baseline B as the mean of known scores with unspecified required coverage. If baseline coverage below100% is permitted, this excludes unknown cases and can inflate B. This is a must-fix contradiction. Simplest correction: require all eligible baseline outcomes to be known, compute B=correct/eligible_count, and invalidate the baseline while any required outcome is unknown. If incomplete baselines are desired, define interval arithmetic and propagate uncertainty into drift instead of taking the observed-only mean.
Also specify E=0 for C7 coverage and zero expected windows for C9 aggregates as NOT_ASSESSED, with no division performed. P=0 is already handled. State that alert generation occurs for each measured window crossing D, even when an interval’s allowed violating-window fraction is nonzero; interval satisfaction and threshold detection are different outputs. Add fixtures for partial baseline, empty populations, and a tolerated but correctly alerted window. Actual N, distribution, timeout and thresholds appropriately remain pre-assessment decisions; illustrative ten-case arithmetic is not sample justification.

2. MEDIUM — C7’s timing bounds require an independently reconstructible pair population.
The K/P to (K+U)/P bounds are sound only when expected pairs P are known. Obligations contain causal parents and sources, while producer sequence/clock domain currently live in observations. If an entire observation disappears, its stream and predecessor/successor pair membership must not be reconstructed solely from surviving telemetry. Add expected stream identity and predecessor/sequence slots to the obligation contract, or an authoritative ordered expected-pair inventory. Declare how alternative terminal outcomes occupy the same required slot. If pair membership or sequence coverage is unknown, report an unproven timing denominator rather than calculated bounds. Test a missing middle event and missing whole stream: the first must retain both expected adjacent pairs, and the second must not improve timing coverage. This is a specification gap, not an assertion that the proposed formula is intrinsically wrong.

3. HIGH — Three-control completion still rests on unverified external evidence and accepted scope.
Neither a schema nor a source-authority map creates an independent expected population, all-zone provider usage, accepted ground-truth labels, or writable ServiceNow workflow. Fixed-batch C9 can be a defensible disclosed benchmark, but cannot silently stand for all production drift. The revision correctly gates these and avoids inventing capability. Execute the probes first and preserve their raw evidence; require organizer resolution of benchmark/breach eligibility before scored runs. A named gap cannot substitute for completion. RoleB also owns labels/windows, ServiceNow, export/query and rechecking: if access work expands, reassign one concrete package to A or cut bonuses early. The explicit two-control ceiling and freeze buffers are appropriate safeguards, not proof of capacity.
