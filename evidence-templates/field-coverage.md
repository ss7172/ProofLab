# Field coverage: what the records carry, and what they do not

Generated at pack-build time from the offline field-coverage audit (raw ledger, stitched store and raw captures; no live call).
**The raw evidence is never edited.** A missing or wrong field is stated here with its substitute witness, and every value the
console shows carries a source tag: `recorded (<field>)`, `witnessed-by:<gateway span | AWS InvokeAgentRuntime | ServiceNow | S3>`,
`joined-from:<artefact>` or `not-recorded`.

Classes used below (stated plainly):

- **NEEDS-AGENT-REBUILD**: the field is written by our recording code (agent images or the orchestrator/collectors) and the named runs are already recorded with frozen, approved agent images; the raw records are never edited, so only a rebuild and a new run can add it. Cannot be fixed before the deadline: the agent images are frozen and approved.
- **PLATFORM**: the platform does not write it and we cannot change the platform; no rebuild of ours can add it.

The audit's own label (FIXABLE-NOW, JOINABLE) is kept in brackets: it means the recorder can be changed for future runs, or the
value can be joined from another artefact in the view; it never means a recorded run was changed.
